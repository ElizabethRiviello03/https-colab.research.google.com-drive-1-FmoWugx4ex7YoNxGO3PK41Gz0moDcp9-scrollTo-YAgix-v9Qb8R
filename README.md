# Reto - Análisis del Progreso Mundial de Vacunación

Este proyecto analiza el progreso de vacunación contra COVID-19 a nivel mundial utilizando datos actualizados de Our World in Data (OWID).

## 📋 Descripción

El análisis incluye:
- 📊 Carga y procesamiento de datos de vacunación mundial
- 🌍 Análisis de tendencias por país y región
- 📈 Visualizaciones interactivas del progreso de vacunación
- 🏆 Identificación de países líderes y rezagados
- 🌎 Análisis específico de América Latina
- 📉 Estudio de correlaciones entre variables
- 📝 Generación de insights y conclusiones

## 📊 Datos

Los datos se obtienen automáticamente de [Our World in Data](https://github.com/owid/covid-19-data), una fuente confiable y actualizada de estadísticas de vacunación COVID-19.

## 🔍 Análisis Incluidos

1. **Exploración de Datos**: Estadísticas descriptivas y estructura del dataset
2. **Top Países**: Ranking de países por cobertura de vacunación
3. **Progreso Temporal**: Evolución de la vacunación a lo largo del tiempo
4. **Distribución Global**: Análisis de la distribución de cobertura entre países
5. **Velocidad de Vacunación**: Países con mayor ritmo de administración
6. **Mapa Mundial**: Visualización geográfica de la cobertura
7. **América Latina**: Análisis regional detallado
8. **Correlaciones**: Relaciones entre variables de vacunación
9. **Resumen Ejecutivo**: Conclusiones y hallazgos clave
